# 떡밥

> 생성기가 매 화 갱신([열림]→[회수]). 열린 떡밥이 소리없이 사라지면 연속성 체크가 잡는다.

## 열림
- [중심] **[[아귀존]] 포식** — 마을을 삼킨 난신, 최종 표적. 9화에서 발원지(빈 제단)에 본체 없이 *조각의 이빨자국*만 있음이 드러남. 10화에서 [[묵야]]가 *돌아서지 않되 '먹으러가 아니라 만나러'* 가기로 정함 — 먼저 먹은 자를 찾아 어디까지 갔는지 묻는 길. 직접 미등장 유지, 표적이 '흩어진 조각'으로 비틀린 상태 지속.
- [장기] **[[묵야]]의 근원** — 굶주림은 어디서 왔나. 10화에서 묵야가 굶주림을 처음 제 바깥에 세워 "너는 내가 아니다"라 *이름 붙임*(내 허기가 아니라 안에 세 든 남의 입). 비밀(아귀존의 씨앗) 방향으로 압력 누적, 이름·정체 미노출. 빙신의 9화 "먹히는 거다"와 포개짐.
- [장기] **포식의 대가 — 굶주림** — 10화에서 빙신에게 겨눈 칼을 *신기술 없이* 거둠: 빙신의 '먹히기 선택'으로 먹이가 안 도망치자 굶주림이 멈칫 + 어머니의 '나눠 먹던' 기억 + 이름 붙이기. "한 번이다, 다음엔 모른다"로 한계 명시 — 1회성. '동행을 먹는가'의 긴장은 봉합됐으나 곤두선 상태 상존.
- [장기] **난신의 조각 — '모으는' 함정** — 빙신의 9화 폭로(조각을 쫓아 먼저 먹은 자를 먹으면 조각이 누적, 죽이는 게 아니라 모으는 길). 10화에서 묵야가 이를 받아들이되 *돌아서지 않고* 먼저 먹은 자를 만나러 가기로(먹기 전에 묻기) — 함정을 알고도 들어가는 능동 선택.
- [중기] **먼저 먹은 자 — 또 다른 식신자** — 묵야보다 앞서 제단에서 아귀존 조각을 먹고 남행한 식자. 10화 끝 [[산자락의 사내]]가 객잔에 직접 등장, *같은 냄새가 한 겹 더 짙음* — 먼저 먹은 자 유력 후보로 굳어짐. 이름 밝히기 직전.
- [장기] **후각 — 포식 권능** — 천 리 후각. 10화에서 양날이 못박힘: 비 소멸 후 *묵야 자신이 먹은 자의 냄새*가 사방으로 퍼져 사냥개·신단 모두 그를 맡음(추적 표지 교체). 사람까지 먹이로 짚는 대가 유지.
- [장기] **나누어 먹기 — 식의 새 결 / 동행** — 빙신 명치 옆 한 줌. 9화 끝 굶주림의 표적이 됐다가 10화에 봉합, 결 유지·동행 한 단계 진전(빙신의 첫 농담 비슷한 말). 호리병 속 빙신 큰 몸이 10화 끝 코앞에 등장 — 회수/재결합 떡밥 가동 여지.
- [중기] **[[빙신]]의 천 년 / 무엇을 아는가** — 9화에 진실을 통째 내놓음. 10화 새 폭로 없이 여파만(묵야의 동요·돌아설지의 갈등을 곁에서 받음). "처음부터"의 구체(천 년 전 무엇을 봤나)는 미노출 유지.
- [중기] **식신자 추격 — 신단** — 10화 풍문 회수+심화: [[회색 무명옷의 사내]]가 손가락 둘 뭉개진 채 *살아 복귀*, 신단이 이를 '신벌'로 덮고 *더 많은 손을 남행*시켜 '그릇 될 사람'을 찾음. 무림+신단 압력 누적.
- [장기] **묵야의 *값*** — 무림의 값 결 유지. 10화 미진전.
- [중기] **식자를 쫓는 무림 별동대 / [[죽립의 사내]]** — 10화 미등장. "값이 올랐다" 상태 유지.
- [중기] **[[회색 무명옷의 사내]]의 정체** — 9화 직접 대면, 10화 풍문으로 *손가락 잃고 생존·신단 복귀* 후속. 재충돌 압력 유지. "너는 그릇이 아니라—"의 끊긴 말 미회수.
- [중기] **[[산자락의 사내]]** — 10화 객잔에 직접 등장(엿보기/스침 패턴 깸). *먼저 먹은 자* 유력 후보로 굳음, 호리병 든 채 마주 앉아 이름 밝히기 직전. "한 번 더 만나면" 약속 회수 단계.
- [중기] **그릇을 앉히는 신단의 손** — 9화 손가락째 반사 포식당해 한계 드러남, 10화 풍문으로 '신벌' 후속. 손의 한계가 굳음.
- [단기] **[[빙신]]의 외부 형상(고정)** — 남의 눈엔 안 보이고 곁 공기만 시리며 김 서림, 묵야에게만 흰 무명옷·발끝 서리의 작은 여인. 10화 객잔에서 곁공기 한기가 짐꾼에게 들킬 뻔해 그림자로 물림(은닉 긴장에 활용). 유지.
- [단기] **[[강가의 사내아이]]** — 10화 미등장. 신단 '그릇 될 아이 단속' 풍문으로 간접 압력 유지. [[회색 무명옷의 사내]] 손 안 정황 지속.
- [단기] **묵야의 인간적 결 — 어머니·누이 기억** (10화 신규) — 흉년에 만두를 반으로 갈라 나눠 먹던 어머니, 누이에게 남기려던 기억. '나눈다'가 굶주림을 멈춘 결의 뿌리. 누이는 십 년 전 그 입에 삼켜짐 — 고향 몰살·복수와 연결.
- [단기] **흑의의 변방 매듭** — 추가 노출 없음. 신단은 *그릇*으로 본다는 결 유지.

## 회수
- **[[묵야]]가 빙신에게 겨눈 단도 (9→10화 회수)** — *기존 수단 없이* 거둠(빙신의 먹히기 선택 + 만두 기억 + 굶주림에 이름 붙이기). 동행 봉합·진전.
- **추적 표지 교체 (9 비 소멸→10화 못박음)** — 비 잔재 소멸 후 추적이 *묵야 자신의 먹은 자 냄새*로 넘어감을 명시 회수.
- **[[회색 무명옷의 사내]] 부상·생존 후속 (9→10화)** — 손가락 잃고 살아 신단 복귀, '신벌'로 덮고 증원 남행한다는 풍문으로 회수+재충돌 떡밥 유지.
- **[[산자락의 사내]] 재등장 약속 ("한 번 더 만나면") (2·6→10화 회수 단계 진입)** — 객잔 직접 등장·이름 밝히기 직전.
- **남쪽 냄새의 발원지 (7→9화 재오픈→10화 진전)** — 발원지가 조각·먼저 먹은 자의 흔적이었고, 10화에 그 먼저 먹은 자 유력 후보(산자락 사내)가 등장하며 회수로 향함.
- **[[백사부인]]의 비 잔재 (1→9화·소멸)** — 소멸 확정 유지, 추적 표지가 묵야 자신의 냄새로 교체됨으로 후속 정리.
- **그릇잡이 '신단도 남으로 간다' / 사냥개·죽립 대면 / 빙신 덜 말한 한 줄 / 짐승 안 결 / 사당 미끼 / 흙길 세 발소리 / 강가 아이 풍문** — 이전 화 회수분 유지.
